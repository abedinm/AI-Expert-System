# AI-Expert-System

Coursework for **CSC4226 — Artificial Intelligence and Expert System** (AIUB).

## Contents

### Lab-01
Python fundamentals — Set, Tuple, Dictionary, list processing, and matrix multiplication.

| File | Description |
|------|-------------|
| [`Lab-01/task1.py`](Lab-01/task1.py) | Takes integers from the user, removes duplicates, sorts descending, filters out multiples of 3 |
| [`Lab-01/task2.py`](Lab-01/task2.py) | Matrix multiplication of two 2D matrices using nested loops |
| [`Lab-01/study-material.md`](Lab-01/study-material.md) | Study notes: Set, Tuple, Dictionary + concepts behind both tasks |
| [`Lab-01/cheatsheet.md`](Lab-01/cheatsheet.md) | One-page quick reference |

## Running

```bash
python3 Lab-01/task1.py     # then type integers, e.g. 9 3 3 7 12 5 8 6 10
python3 Lab-01/task2.py
```
